# 1. HOW TO USE TURNAROUNDS AS REFERENCE ANCHORS

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. GENERATE TURNAROUND SHEET FIRST (Front View, Side View, Back View)       │
│ 2. UPLOAD TO MIDJOURNEY / GOOGLE FLOW AS IMAGE REFERENCE                    │
│ 3. USE --cref [URL] --cw 100 IN MIDJOURNEY OR ADD AS "INGREDIENT" IN FLOW   │
│ 4. ALL SUBSEQUENT PANELS WILL LOCK 100% TO THIS EXACT COSTUME & FACE        │
└─────────────────────────────────────────────────────────────────────────────┘
```

* **Standard Turnaround Aspect Ratio:** Always use `--ar 16:9` for horizontal model sheets.
* **Global Turnaround Style Modifier:**  
  `character design turnaround sheet, model sheet, front view, side profile view, back view, 3/4 view, full body standing pose, neutral grey background, 16-bit arcade pixel art style, Capcom CPS2 aesthetic, Shinkiro character design, sharp clean pixel outlines, flat colors, no anti-aliasing, highly detailed reference sheet.`
